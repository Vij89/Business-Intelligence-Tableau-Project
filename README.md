# 📊 Sales Performance Dashboard – Tableau

## 📌 Project Overview

The **Sales Performance Dashboard** is an interactive Business Intelligence project developed using Tableau Public. The purpose of this project is to analyze business sales performance, profitability, regional contributions, product category performance, and year-over-year trends through meaningful data visualizations.

This dashboard transforms sales data into actionable business insights, helping users understand overall performance, identify trends, evaluate profitability, and monitor key performance indicators (KPIs).

The project demonstrates practical skills in data visualization, business intelligence, analytical thinking, dashboard development, and data-driven decision-making.

## 🎯 Project Objectives

The primary objectives of this project are:

- Analyze overall sales and profit performance.
- Monitor important business KPIs.
- Evaluate sales trends and business growth over time.
- Compare current-year and previous-year performance.
- Identify high-performing and low-performing product categories.
- Understand regional sales and profitability contributions.
- Present business data through interactive and user-friendly visualizations.

This dashboard is designed to help answer important business questions:

1. How is the overall sales performance?
2. Which regions contribute the most to total sales?
3. Which product categories generate higher profits?
